# AI Study Planner

An adaptive study planner that changes daily based on performance.

## Problem
Static timetables ignore:
- bad days
- burnout
- inconsistent effort

## Solution
A feedback-driven planner that:
- adapts difficulty
- adjusts hours safely
- tracks streaks
- reports weekly insights

## How It Works
1. Generate a plan
2. Study
3. Submit feedback
4. System adapts automatically

## Why It’s Different
- Trend-based intelligence (not one-day reactions)
- Burnout detection
- Explainable decisions
- Monetization-ready (premium reports)

## Tech
- FastAPI
- SQLite
- SQLAlchemy
- Minimal frontend (HTML/JS)

## Demo
Open `frontend/index.html`, generate a plan, submit feedback, view metrics.
